# Smart Study Assistant

Smart Study Assistant is an AI-powered educational application designed to make learning easier, smarter, and faster. It is built using Python, Streamlit, Ollama, and Gemma 3.

## Features
- Upload PDF study materials
- Extract PDF text
- Generate easy-to-understand summaries and multiple-choice quizzes
- AI-powered learning assistance to test your knowledge and prepare effectively for examinations
